## Machine-readable configuration

Commercial terms that are **configuration, not copy** live in
[`../config/commercial.json`](../config/commercial.json) so that pricing and
policy parameters can change without a code change. Code must read fees, limits
and periods from that configuration rather than hardcoding them.

## What remains external

1. Legal review and sign-off by qualified Botswana counsel.
2. Confirmation of the applicable regulatory perimeter (payment services,
   AML/CFT reporting, consumer credit) with the relevant authority.
3. Execution of provider and partner contracts.
4. Registration with the Information and Data Protection Commission.
